# AquaPeelter

An IoT laundry-wastewater filtration system utilizing a banana-peel bio-adsorbent filter, monitored and controlled through a dedicated mobile application. 

## Tech Stack
* **Hardware:** ESP32 NodeMCU.
* **Sensors:** pH (0–14), Turbidity (NTU), TDS (ppm), and optional temperature (°C)[cite: 13].
* **Backend:** Node.js/Express with MongoDB (Mongoose), hosted on Render[cite: 13].
* **Frontend:** React Native mobile app built with Expo SDK 57 and React Navigation 7[cite: 13].
